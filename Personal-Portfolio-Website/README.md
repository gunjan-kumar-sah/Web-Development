# 🚀 Advanced Personal Portfolio Website

A modern, responsive, and recruiter-friendly Personal Portfolio Website built using HTML, CSS, and JavaScript. This portfolio showcases professional skills, projects, certifications, education, and contact information in a visually appealing and interactive way.

---

## 📌 Overview

This project is designed to create a strong online presence for developers, students, and technology enthusiasts. It provides a professional platform to showcase technical skills, projects, achievements, certifications, and career goals.

The portfolio follows modern UI/UX principles and includes interactive animations, responsive layouts, dark/light mode support, and a professional design suitable for recruiters and hiring managers.

## ⚙️ EmailJS Setup

This portfolio includes EmailJS integration for contact form functionality.

### Required Information

* Public Key
* Service ID
* Template ID

### Replace in script.js

emailjs.init("YOUR_PUBLIC_KEY");

emailjs.sendForm(
"YOUR_SERVICE_ID",
"YOUR_TEMPLATE_ID",
form
);

After configuration, visitors can send messages directly from the portfolio website.
